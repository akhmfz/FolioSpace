# FolioSpace v4 — Four distinct portfolio directions

## Research basis

The redesign is informed by the 118 entries present in the user's copied Portfolio Ideas list. The supplied categories contain 66 Professional, 30 Creative, 18 Minimalist, and 4 Academic examples. Exact repositories, licenses, and current live screenshots were not included in the pasted text and could not be verified during this pass. See `REFERENCE_RESEARCH.md` for the evidence boundary and shortlist.

## What changed

- Minimalist is now a text-first editorial site with project notes, a writing index, and a current-focus section.
- Professional is now a recruiter-friendly profile with experience, case studies, education, and practical skills; decorative dashboard metrics were removed.
- Creative is now a work-first art-directed portfolio with custom CSS project compositions rather than generic stock-photo project cards.
- Academic is now a scholarly profile organized around affiliation, research interests, publications, teaching, and correspondence.
- Homepage and catalog copy now describe four complete personal websites with distinct personas rather than abstract template previews.
- Four demos retain independent HTML and CSS. Catalog and homepage iframe previews remain intact.

## Validation

- JavaScript syntax checks: run `node --check` on all files in `assets/js`.
- HTML parsing and local path checks: run the project's validation script / inspect all four demo pages.
- HTML/CSS were rendered offline for a layout sanity check; browser visual QA is still required in Live Server at desktop, tablet, and mobile widths.
- Portrait images currently use remote Unsplash URLs and need final licensing/availability review before production.

## No upstream code copied

This is an original redesign based on source-list metadata and broad design inferences. No code, photos, or assets were copied from the named reference websites. Confirm exact upstream repository URLs and licenses before any future adaptation.
